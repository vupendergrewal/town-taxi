# Town Taxi Dunedin

Website for Town Taxi, a 24-hour taxi in Dunedin, New Zealand.

The site is static HTML, CSS, and JavaScript. There is no build step. Upload the site folder to ordinary hosting and it runs as it is.

- Booking form sent to the desk
- WhatsApp and click-to-call
- Day and night theme
- Layout for phone and desktop
